## 适合谁用

- 中学、大学化学的预习、复习与作业核对
- 教师备课、出题时快速查找反应与现象
- 需要随手确认某个反应怎么写、怎么配平的化学爱好者

## 一次查询能得到什么

- **配平方程式**：按原子守恒与电荷守恒自动配平，直接给出可抄写的完整式子
- **氧化还原分析**：标出化合价变化、得失电子数与氧化剂／还原剂
- **实验现象提示**：沉淀、气体等结果信息
- **分子／离子方程式**：一键在两种写法之间切换
- **化合价标注**：开启「显示化合价」后，每种物质的化合价直接标在化学式正下方
- **物质资料卡**：中文名、英文名、别名、类别、状态、外观、溶解性、氧化数、摩尔质量、元素组成，以及概述、制备方法、用途、安全提示等条目
- **相关反应**：与当前反应共享反应物或产物的其他方程式，方便顺着一条反应继续查下去

## 三种查询方式

1. **完整反应式**：同时写反应物和产物，返回唯一匹配的方程式。
   例：`H2SO4 + NaOH = Na2SO4 + H2O`
2. **只写反应物**：列出包含这些反应物的多个可能反应，按常见程度排序。
   例：`C2H5OH + O2`
3. **只写一种物质**：进入物质资料页，查看性质、别名与关联反应。
   例：`CH3CHO`

「自定义搜索」页面可以分别指定必须出现的反应物与产物，适合反查某一类反应。

## 输入写法

- 分隔符用 `=` 或 `→` 均可，例如 `Fe + O2 = Fe3O4`
- 离子用冒号加电荷表示：`Fe:3+`、`Cl:-`、`Cr2O7:2-`、`OH:-`
- 不需要写系数，系统会自动配平；化学式大小写按常规书写即可
- 括号基团、结晶水按化学式习惯书写，如 `Ca(OH)2`、`CuSO4*5H2O`

## 内容范围

- 收录两万余条常见无机与有机反应，以及对应的物质资料条目
- 每条记录包含参与者、配平系数、反应条件与物态信息
- 物质条目整理自公开化学资料，包含名称、别名、性质与用途等

## 设置与数据

页面右上角「菜单」中可以切换浅色／深色／跟随系统外观，并开关页面动效。

搜索历史、收藏和外观选择保存在当前浏览器的本地存储中：

- 不会上传到服务器，也无需登录
- 换浏览器、换设备或清除浏览器数据后不会保留
- 同一域名下的不同页面共享这些记录

## 使用提示

- 配平成功只说明原子与电荷守恒，不代表该反应在真实条件下一定发生
- 反应条件、现象与实验安全应以教材、手册和专业指导为准，本站内容仅供学习参考
